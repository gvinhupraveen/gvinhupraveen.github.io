# G. Vinhu Pprawin: portfolio

Static site with no build step. Open `index.html` to preview.

- `index.html`: home (intro, highlights, latest projects, capabilities, experience, education, skills, recognition, contact)
- `projects.html`: all projects
- `projects/*.html`: one page per project, with previous/next navigation
- `css/style.css`: all styling
- `assets/`: images, videos and resume

Deploy: create a GitHub repo, upload these files to the root, then Settings → Pages → Deploy from branch → main / root.
